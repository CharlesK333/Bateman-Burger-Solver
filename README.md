# Bateman-Burger-Solver
The main objective of this project is to make a means of numerically solving Burgers equation, but also training a model to solve it as well. The results of the comparison will be attached in the repository as well. 
There will be two numerical methods used in this project. The first is a finite difference method, then the second will be a reduced order model. For the second one, it will have a sperate results document that the finite difference, as I will be attempting to both reduce the order but also assume linearity of Burgers Equation, which those two properties are not properties of Burgers. 
The next portion will be using PINNS to train a model, and hopefully find a solution to this equation as well.
